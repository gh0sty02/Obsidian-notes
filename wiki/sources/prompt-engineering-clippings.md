# Prompt Engineering Clippings

## Abstract

Batch summary of prompt-engineering clippings covering general prompting principles, Claude-specific tutorials, prompt shortcut patterns, and role-specific job-search prompts.

## Included Clippings

- `Prompt Engineering for AI Guide.md` - Google Cloud explanation of prompt engineering concepts and examples.
- `Anthropic's Interactive Prompt Engineering Tutorial.md` - Claude-oriented interactive tutorial repository.
- `AI Prompt Shortcuts Cheat Sheet.md` - compact patterns for improving Claude/ChatGPT outputs.
- `AI Prompts for Every Job Role.md` - large prompt collection for resumes, job targeting, cover letters, skill gaps, and role-specific career tasks.
- `Claude Architect Cert and AI Courses.md` - certification/course clipping that overlaps with Claude prompting and AI learning paths.

## Key Claims

- Prompt quality improves when requests specify task, context, constraints, examples, and output format.
- Prompt shortcuts are mostly reusable control patterns: ask for critique, transformation, comparison, extraction, role-play, or structured output.
- Career-oriented prompting is a practical use case: resume tailoring, company targeting, cover letters, interview preparation, and time management can be converted into repeatable prompt templates.
- Claude-specific learning resources reinforce the need to test prompts systematically rather than rely on a single successful example.

## Methodology

The set mixes vendor documentation, GitHub tutorials, and Substack-style prompt lists. Vendor documentation is stronger for durable principles; prompt lists are useful as pattern libraries but should be tested and adapted.
