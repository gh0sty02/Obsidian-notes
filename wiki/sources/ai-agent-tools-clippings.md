# AI Agent Tools Clippings

## Abstract

Batch summary of AI-agent and AI-tool clippings from `raw/Clippings/`. The set expands the wiki's agent tooling coverage beyond memory and orchestration into research skills, job-search automation, code explanation, creative media tools, model hubs, and AI-assisted productivity.

## Included Clippings

- `MemPalace AI Memory System.md` - open-source memory system for persistent AI-agent context.
- `Last30Days AI Research Skill.md` - agent skill for recent web/social research across Reddit, X, YouTube, Hacker News, Polymarket, and the web.

- `AI Job Search with Claude Code.md` - example of using Claude Code to rank and triage hundreds of job offers.

- `civitaicivitai A repository of models, textual inversions, and more.md` - model and asset repository for generative AI workflows.
- `Discover AI Tools & Hacks for Marketing.md` - directory-style clipping of AI marketing tools and hacks.

## Key Claims

- Useful agent tooling clusters around a few recurring capabilities: persistent memory, web/current-event research, orchestration, application automation, code comprehension, and productivity workflow automation.
- Open-source agent tools increasingly package an opinionated workflow rather than just a library: MemPalace provides memory structure, Last30Days provides a research routine, AIHawk applies to jobs, and Inbox Zero manages email.
- Claude-oriented tools are emerging as a distinct ecosystem: Pixa plugs media operations into Claude surfaces, while Claude Code examples show AI agents being used as personal workflow automation.

## Methodology

These are web clippings, not benchmarked evaluations. Treat repository claims as leads to inspect, not as verified performance conclusions.
