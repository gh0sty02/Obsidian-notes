# Technical Interview Prep

Technical interview preparation in this wiki spans coding interviews, system design, AI engineer interviews, cloud/backend fundamentals, frontend interviews, and behavioral/story preparation.

## Core Tracks

### Coding / DSA

Use [[concepts/dsa-patterns]] as the backbone: learn patterns first, then solve curated lists. The new clipping batch adds NeetCode 150, InterviewBit, TypeScript algorithm courses, JavaScript visual examples, Python competitive-programming cheatsheets, and interactive visualizers.

### System Design

Use [[concepts/system-design-fundamentals]] as the framework: requirements, non-functional constraints, capacity estimates, high-level architecture, and deep dives. The system-design clippings add external primers, 10-day study plans, and diagram/simulation tools.

### AI Engineer Interviews

The AI engineer question-bank clipping points toward a mixed interview surface:

- ML and LLM fundamentals
- Prompt engineering and RAG concepts
- Coding rounds
- System design for AI products
- Production concerns such as evaluation, latency, cost, and observability
- Behavioral and situational rounds

### Cloud / Backend

Cloud engineer and AWS course clippings connect interview readiness to [[concepts/aws-architecture]], DevOps, deployment, and operational thinking.

### Frontend

BFE.dev, JavaScript concept lists, TypeScript type challenges, CSS practice, and UI resources support frontend-heavy interview loops.

## Practical Strategy

- Keep one active coding list, one active system-design source, and one role-specific interview bank.
- Do not collect resources indefinitely; convert each resource into a weekly practice schedule.
- Pair learning with output: notes, solved problems, design diagrams, or small projects.
- For AI engineering roles, prepare examples that connect LLM knowledge to real product trade-offs.
