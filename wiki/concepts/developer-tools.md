# Developer Tools

Developer tooling resources in the clipping batch are best treated as a practical toolbox: references, utilities, open-source products, and example apps.

## Categories

### References and Practice

Resources like 30 seconds of code, Exercism, cheat sheets, Git recovery guides, and VS Code shortcut sheets are quick-reference material. Use them when solving a concrete problem or building fluency in a language/tool.

### Infrastructure and Backend Tools

- Infisical - secrets, certificates, and privileged access management.
- Coolify - self-hosting/deployment platform.
- Turso - distributed SQLite-oriented database platform.
- Supabase - Postgres-backed app platform.

These connect to [[concepts/system-design-fundamentals]], [[concepts/postgresql]], and deployment architecture.

### Open-Source SaaS Alternatives

The clippings include alternatives for scheduling, documents/signatures, forms, project management, link attribution, and resume building. These are useful both as products and as implementation references.

### Portfolio Seeds

Project-idea lists, OSS galleries, and full-stack example apps can become portfolio projects if scoped around a clear user problem and shipped with production-quality documentation.

## Use Rule

Promote a tool from "interesting" to "active" only when it supports a current project, study plan, or interview goal.
