# Frontend Design Resources

Frontend design resources in the clipping batch support practice, inspiration, reusable visual assets, and communication artifacts.

## Practice

- 100 Days CSS Challenge for CSS fluency.
- BFE.dev and frontend interview clippings for interview-specific practice.
- TypeScript type challenges and JavaScript concept lists for language depth.

## Assets and Motion

Animated icon libraries, LottieFiles, SVGator, SVG illustration libraries, and stock-resource directories can speed up interface building. Use them selectively: visuals should clarify the product or workflow rather than decorate the page.

## Inspiration and Patterns

UI/UX flow libraries, Awwwards, open-source UI element libraries, and design-resource catalogs are useful when exploring interaction patterns or visual direction.

SystemDraw-style tools belong here and under [[concepts/system-design-fundamentals]] because diagrams are part of explaining system structure clearly.
